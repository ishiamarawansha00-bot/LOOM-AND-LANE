# 🧵 LOOM-AND-LANE - E-Commerce Web Application

A fully responsive e-commerce web platform designed for showcasing clothing catalog, managing shopping carts, and interactive checkout.

## 📌 Project Overview
LOOM-AND-LANE is a modern web application built to deliver a seamless online shopping experience. It features complete front-end user flows including product listings, dynamic shopping cart management, seamless checkout navigation, and an interactive AI chatbot assistant.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Features:** Dynamic UI logic, Chatbot functionality, Shopping Cart simulation

## 💡 Key Features
- **Product Catalog & Details:** Browse and view specific product pages (`listing.html`, `product.html`).
- **Interactive Shopping Cart:** Dynamic cart updates and checkout pages (`cart.html`, `checkout.html`).
- **Smart Chatbot:** Integrated JavaScript chatbot assistant (`chatbot.js`) to assist users.
- **Responsive Design:** Optimized across desktop and mobile devices.
